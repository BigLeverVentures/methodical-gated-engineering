# Plan — Add a report command

## North Star

"Functions that return the right answer for every input they accept, and a clear error for every
input they do not." Adds a `report` command that prints the variance of a file's numbers.

**Left short, on purpose:** no other statistics yet; they are separate units.

## Goal

A developer can run `report` on a comma-separated file and get its variance, or a clear error for a
file with no numbers.

## Deepen score

- A relied-on interface: `readers.load_rows` is called by other tools.
- Three or more modules: calc.py, report.py and cli.py change.

**Score:** 2 of 6 → deepen

## Approach

1. Add `variance` to calc.py, raising an error on an empty list.
2. Add report.py and the `report` command in cli.py.

## Acceptance tests

1. The variance of 1, 2 and 3 is correct — run the Python tests; a pass is a green run.
2. A file with no numbers is an error, not a number — same run.
